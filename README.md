🛡️ PhishGuardAI
**AI-Powered Phishing Detection System**
PhishGuardAI is a web-based application that uses Machine Learning to detect and identify potentially malicious or phishing URLs.

🚀 Features
* 🔍 Phishing URL detection
* 🤖 Machine Learning-based prediction
* 🌐 Simple web interface
* ⚡ Fast URL analysis
* 📊 Prediction result display

🛠️ Technologies Used
* Python
* Flask
* Machine Learning
* HTML
* CSS
* JavaScript

```text
PhishGuardAI/

├── app.py

```

 ⚙️ Installation

Clone the repository:
```bash
git clone https://github.com/karpahadharshu-tech/PhishGuardAI.git
```

Navigate to the project folder:
```bash
cd PhishGuardAI
```

Create and activate a virtual environment:
```bash
python -m venv venv
```

Activate it on Windows:
```bash
venv\Scripts\activate
```

Install the required packages:
```bash
pip install -r requirements.txt
```

▶️ Run the Application
```bash
python app.py
```
Then open the local Flask server in your browser.

🎯 Purpose
The purpose of PhishGuardAI is to provide an easy-to-use system for identifying suspicious URLs and improving awareness of phishing threats.
